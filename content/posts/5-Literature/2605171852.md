## 大纲

**首先**，我们会介绍Motivating example，然后我会通过一个曲线拟合的例子向大家展示，我怎么样从一个表格的形式引入函数的近似

**第二节**，虽然它是一小节， 但是是非常关键的一节，这一节讲的是什么呢？讲的是你给我一个策略，我怎么样来进行policy evaluation，也就是我估计出来它的state value，那这边具体的就包括我怎么样建立一个object function，我怎么样去做优化，我应该用什么样的函数去近似等一系列

这一节，其实我们不会介绍我怎么样去顾及action value，我怎么样得到最优的策略等等，但是它占得分量是非常重的，因为它会揭示value function approximation非常基本的想法，那你明白了这个之后，之后的算法其实就很简单了，那这里面我们会介绍3个算法

第一个算法是把之前的Sarsa推广到怎么把这个value function approximation结合起来

然后第二个是我们之前的Q-Learning怎么把它和value function approximation结合起来

第三个就是非常著名的Deep Q-Learning，之后我会给一个小结，下面我们来看第一部分

到目前为止，其实我们没有明说，但是实际上我们的state value和action value，全部都假设它们是用表格的形式表达出来，不管是在贝尔曼公式还是之前的所有的算法当中，那这是什么意思呢？

那这个表格实际上就对应的是一个q table也就是qπ(s,a)，qπ(s,a)它有两个索引一个是s一个是a，其实它就分别对应了这个表格横向和竖向，然后我可以把qπ的值放到这个表格当中去

类似地如果是vπ的话，那它实际上就对应了一个一维的这样的一个表格，在编程的时候我们实际上就把这些表格，重组成向量矩阵或者是数组。

**我使用表格的好处是什么呢？** 就是它是非常的直观，然后我去分析的时候也是比较简单的，**但是它的坏处**就是它没办法处理，非常大的state space或者是action space，或者是你的state space是连续的时候，那这个表格显然是不能处理的

当然有的同学可能会说，我一个连续空间，实际上我可以通过表格网格的方式把它给离散化，那离散化它总是存在问题，就是<u>当你离散的很密的时候</u>，那你离散的这些网格又太多了，处理起来还是非常地吃力

<u>当你离散的很稀疏的时候</u>，又不能很好地去近似这样一个连续空间

总而言之，当state space或者action space比较大的时候，我们在存储它们的值的时候会面临问题，同时还有一个问题是什么呢？就是泛化能力

**泛化能力是什么呢？** 

就是当你有很多的state action pair，你必须全都访问到它们，你才能估计出来它们的值，但是因为有太多了我不可能全部都访问到

**那这时候怎么办呢？** 

那有很多我可能就估计不到它的值，但是之后我如果我们把函数近似引入进来的话，大家就发现这两个问题就能够被解决掉了

## 例子

**下面我通过一个例子来介绍一下**

value function approximation它的基本的思想是什么，这个例子我们这里边有n个状态 s1到sn，这个符号代表是state space里边所有状态的个数

我假设它是n ，然后每个s这里边考虑很简单的情况，它对应的就是一条直线上的一些数值，然后每个s又有一个state value

那这个图当中的纵轴标就是state value，这些state value分别就对应了这些离散的圆点

现在的问题是什么呢？

我的状态的个数非常非常多，如果我要把它全部存储下来，其实要花非常大的内存，那有没有可能我用一个曲线把这些离散的点给它串起来

然后用这个曲线来代表这些点呢？为什么要用曲线呢？

就是因为这个曲线它所对应的参数的个数其实是非常少的，我只要存储比较少的参数，我就能来表示所有的这些状态它的state value，答案肯定是可以的，那最最简单的情况就是我们用一条直线来拟合这些点

**直线的方程是什么呢？** 

如果横坐标是s的话，就是$as+b$，a和b在这里边是两个参数；然后这个函数我用vhat来表示，v就是代表是对值的近似，hat一般是代表估计的意思，然后这个vhat是两个量的函数 

第一个量是状态

第二个量是参数$w$  

这个w是怎么回事呢？就是我可以把as+b这样一个形式写成两个向量相乘的方式，第一个向量是包含s的这样一个量，我用φ来表示；

第二个向量是包含参数的量，我用w来表示，那显然这两个向量相乘还是得到了sa加上b，然后这个vhat最后就可以写成φT(s)w，然后这里边的$w$， $φ$实际上它们是有名字的

- w就叫parameter，因为它是这个向量是parameter vector

- 然后这个φ它是叫feature vector 特征向量 

注意在这个里边vhat是对w成一个线性的关系，当然也可以成非线性的关系

我们先从最简单的情况来考虑，那我们用这个直线来进行拟合，它能带来哪些好处呢？

刚才如果我们用表格的形式或者不用曲线来拟合的形式，我们需要存储非常多个state value，但是现在我们只要存储两个值就可以了，也就是这个w所对应的这两个值，为什么呢？

就是我想去找到这个vπ(s)，当然我现在是一个近似的vhat(s,w)：

第一步，我先计算出来φ(s)， 这个叫特征向量

第二步，我把这个φT(s) 乘以w我就计算到了vhat，所以我只需要保存w就可以了，那这样就极大地节省了很多的内存，但是这个好处其实并不是免费的，它是有代价的

**是什么代价呢？** 

就是你这个近似不是那么的精确，比如说这个离散的点，它是这样一个不是严格一条直线，那你非要用一条直线去给它拟合，那在很多点上，其实你所估计出来这个vhat和vπ(s)还是有比较大的区别的

这个也是为什么这种方法叫value function approximation的原因，它是一种近似

**有的同学说了我用直线来拟合不是很准确，那我能不能用更高阶的曲线来拟合呢？** 

答案当然是可以的，比如说我们这里考虑一个二阶的曲线 

**二阶曲线是什么呢？** 

就是写成这样一种形式，vhat是等于as平方加上bs加上c，那这个同样可以写成φT(s)乘以w这样一种形式，在这种情况下φ和w它的维数增加了，也就是意味着我要存储更多的值

但是它的好处就是我拟合的精度有可能是提高的，当然这里边我还想提出来一点，就是这时候这个函数对s来说它是一个非线性函数

但是它对于abc就是参数来说，它实际上是一个线性函数，它的非线性都被放到了feature vector里边

所以这时候针对这个w来说vhat是一个线性的函数，当然我可以用比如神经网络等等来做一个非线性的拟合，那时候这个函数对w来说就是一个非线性的

我们还可以继续增加曲线它的阶数，然后甚至用更加复杂的这种曲线来拟合这些点，那么它的**好处**就是我可以更加准确地去拟合这些点；但是它的**坏处**就是它需要很多更多的参数

## 例子小结

通过刚才的这几个例子我们来做一个简单的总结，第一个就是value function approximation，它的idea是什么呢？其实很简单

就是我用一个函数来拟合这个vπ(s)，然后这个函数里边有个参数w，所以它被称为parameterized function， w就是parameter

**这样的好处是什么呢？** 

首先第一个是能<u>节省存储</u>，因为如果我有非常多个状态，我要存储非常多个state value，但是现在我只需要存储w就行了，w的维数可能是非常非常低的，所以我能节省大量的存储

第二个好处是什么呢？就是<u>泛化能力</u>，这个我通过一个图来给大家展示一下

假如说这个是s1 s2和s3， 那它们是比较相邻的，第一种情况我们是用table的这种表达方式，那这时候 比如说最开始的时候它们的value是这样的，然后我有一个episode我访问到了s2， 那我就可以更新s2，我更新s2的value之后它跑到了这里，那这是表格的形式注意这里边的s1和s3，因为它们没有被访问到所以它们的值是保持不变的

但是如果我用了函数之后情况就会发生改变

同样是s1 s2和s3 如果我访问了，假设原来是有一个函数，这个函数是一条水平线在这里；如果我访问了s2，我发现它的值不应该是这个，它的值应该是这个，它就会改变，但是改变的方式是什么呢？

我不是直接改变s的值，我是改变这个w，我一旦改变了这个w，整个函数就发生了变化，它可能就变成这个样子了

那所以在这时候 ，虽然s1和s3是没有被访问到的，但是因为s2改变了w ，也就造成了s1和s3它们的值，也发生了变化，这个就是泛化能力，也就是说我不需要把所有的状态我全都访问到，我访问其中的一些，那么相邻的这些它自然也就，它的值也就能够比较准确的被估计出来了，所以这个也是value function approximation非常重要的一个优势。

## 原理：目标函数介绍

通过刚才的motivating example，我相信大家对value function approximation，有了一些直观的理解 

下面我们就来正式地介绍，也就是第二节，第二节又包含了很多小节，这一节在我们这次课当中是非常重要的

因为它揭示了value function approximation这种方法，它的思想还有非常多的概念和细节，当你理解了这一节之后，我们后面再学习345这些算法的时候就会容易很多

下面我们来首先看一下objective function，首先vπ(s)是对s的真的state value vhat是它估计的一个值

我们的目标就是让这个估计的值尽可能地去接近真值，然后当这个vhat函数它的结构确定的时候，比如说之前我们知道它是一个线性的函数，它是一个直线抛物线或者说它是一个神经网络

当它神经网络的结构确定的时候，剩下我们可以调节的就是w，我们要做的就是找到一个最优的w，使得这个vhat尽可能地去接近vπ，那所以这个问题实际上就是一个policy evaluation的问题，因为你给我一个策略 ，我要找到一个近似的函数vhat，尽可能地去接近它真实的state value，然后之后我们会再推广得到这个action value，再推广得到怎么样去找最优的策略 

所以我们一步一步来，我们先看怎么样做policy evaluation，这个和我们上节课介绍TD算法其实也是一样的，下面我们的目标就是找最优的w，怎么找呢？

实际上我们下面有两步

第一步是我们要正式地把目标函数给很好地定义一下

第二步就是去优化这个目标函数

所以我们先来看怎么去定义目标函数，这个就是目标函数，这个是value function approximation，这种方法它的目标函数$J(w)$， w是我们要优化的参数

它等于什么呢？

这个是一个expectation，后边是一个误差，什么的误差呢？

是state value真值和估计值之间的误差，然后这边有一个平方，那这时候我们的目标，就是找到最优的w，然后去优化这样一个目标函数

值得指出的是这里边s实际上是一个随机变量，随机变量它一定是有probability distribution的，那么s它的概率分布是什么呢？

这个问题换另外一个角度来问，就是说这里边不是有一个expectation吗？

expectation本质上它就是做average，我对所有的状态求一个平均

这个平均应该怎么个平均？

所以这是一个问题的两个问法，这个probability distribution对很多初学者，初次接触value function approximation可能会比较迷惑

所以我们下面重点来介绍一下，实际上我们有几种方法 

**下面我们来介绍2种**

 

第一种是非常直观也最容易想到的，是什么呢？uniform distribution也就是平均分布，它的意思是我把所有的状态，把它们认为是equally important，大家都是平等的，那我给每一个人的概率或者说给每一个人求平均时候的权重都是一样的

那我一共有$n$个状态， 所以每一个人的概率或者权重就是1/n，在这个情况下，这个是目标函数我们求expectation

根据定义我们就得到了右边这个，这个是它的概率本来应该是在里边的，我就把它给提出来了，因为每个人的概率都是相同的

**所以这个值，大家看一下是什么呢？**

就是所有的状态估计的误差的平方和然后再求平均，虽然这个平均分布是非常直观的，但是这里边有一个问题，是什么问题呢？

就是我们这里假设所有的状态它们都是平等的，它们是同等重要的，但实际上可能不是这么回事

为什么呢？

比如说我的目标是要从某一个状态出发，然后到达目标状态，那么目标状态和接近于目标的那些状态，其实它们是更加重要的，但相反有一些状态

它可能离目标状态非常非常远，那它们就不太重要，我肯定希望给那些重要的状态更大的权重

更大的权重意味着什么呢？意味着它们估计的误差会更小，那些不重要的状态它们的权重比较小，即使它的估计的误差比较大也没有太大关系，反正我可能不会访问到它或者很少访问到它

有了这样一个想法我们就引入第二个概率分布**stationary distribution**， 这个实际上也是在value function approximation方法当中所使用的

stationary distribution它是非常重要的一个概念，它描述了什么呢？

描述了long-run behavior

我现在稍微介绍一下，之后我会给一个例子，大家会更加清晰，什么叫long-run behavior呢？

就是我从某一个状态出发，然后我按照一个策略我采取action，然后我不断地去和环境进行交互，然后我一直采取这个策略，采取了非常非常非常多次之后，实际上我就达到了一种平稳的状态

在那个平稳状态下我能够告诉你，在每一个状态agent出现它的概率是多少，之后大家通过一个例子会更清晰地了解

下面我们就先知道反正它就是一个概率分布，然后我用dπ来表示dπ(s)就是在s它的概率，因为它是概率分布，所以它在每一个s上，它的概率都是大于等于0的，并且概率的和应该是等于1的，然后在这种情况下，那很自然根据expectation的定义

这个目标函数就可以写成这个形式，那这里面这个dπ实际上就扮演了权重的意思

我某一个状态它的权重比较大，那我就会让它估计的那个误差会更小一些，**实际上这个dπ还有一个意思是什么呢？** 

就是它在达到平稳状态之后agent出现在那个状态的概率，或者说那个状态被访问的概率是多大，如果它很大，这个数就比较大

意味着我希望那个状态它的估计误差是比较小的

下面我再稍微介绍一下stationary distribution，实际上它的内涵是非常丰富的，从字面上来理解stationary distribution也不难理解

首先它是一个distribution就是状态的概率分布，如果是在求加权平均的时候，你可以认为它实际上就是那个状态的权重，然后它是stationary distribution  stationary平稳，也就是我从现在出发然后执行某个策略

又跑了很多很多步之后，所达到的一种概率的分布，所以那时候就已经达到是平稳的状态了

stationary distribution又被称为steady-state distribution或者叫limiting distribution；limiting就是极限，就跑了很多步之后

那它在这节课 value function approximation以及下节课policy gradient当中都扮演了非常重要的角色，特别是在定义objective function的时候，就会出现这个distribution

**我下面通过一个例子来展示一下相信大家就会比较明晰，这个例子是什么呢？**

我现在有一个策略，就是这个策略，大家看一下这个策略，它是一个探索性的策略，因为每一个action它都有正的概率去选到，但是它也有比较大的一个概率去选择某一个特定的action

所以它有一定的倾向，比如说在这两个状态它是向下，在这是向右 ，在这的时候它有比较大的概率是保持原地不动

我们下面要做的是什么呢？

就是我让agent从一个状态出发然后跑很多次，就根据这个策略我们看一下会发生什么样的事情，假如说我有一个episode，这个非常长，从一个状态出发，那这个episode会访问每一个状态很多次

那我假设它访问s的次数我用nπ(s)来表示，nπ(s)除以它访问所有状态的次数也就是episode的长度，这个比值我用下面这个图表示出来了，另外这个比值实际上可以来近似stationary distribution

首先我们来看一下，下面这个图，这个图是什么意思？

横坐标是我们episode的步长，我们现在跑了一个episode，它一共有1000步，纵坐标就是上面这个比值，大家可以看到访问不同的状态它所得到的比值，或者说那个状态被访问的概率是不同的，在开始的时候波动还是比较大的，但是随着step越来越多最后都趋向了平稳

所以这个就是什么叫stationary平稳，什么叫long-run？

就是我跑很多次之后它就会趋向于平稳，那它们的每一个比值或者是概率都会收敛到一个具体的值，那我们以s4 以这条紫色的线最上面这条线为例

我们把所有的数据全放到一个集合当中，这个花的字体B，花括号这里面就代表一个集合，里边的每一个元素就是一个experience sample，它是从s出发take action a，得到的reward是r跳到的下一个状态是s'，这样一个集合有一个名字叫做replay buffer

我把它放到这个集合当中我下一步，我每次要训练神经网络的时候我不是说，谁先来的我就先用谁来训练神经网络，而是说我把它们全混到一起，然后从这个集合当中去拿一些样品出来，来训练这个神经网络网络，然后在拿的时候，就是拿过来再用的这个过程
