## 基本思路

各位同学大家好，欢迎回到我强化学习的课程，这是我们的第9次课，这次我们将会介绍，非常重要的policy gradient的方法，这是我们课程的地图，经过长途的跋涉我们已经来到了这里，第九次课第九章，基本上已经接近我们课程的尾声了，虽然说快到最后了但是并不意味着内容不重要，恰恰相反内容是越来越重要，为什么？

因为policy gradient的方法以及下节课我们将会介绍的actor-critic的方法，这个是现在最流行的，相对来说性能也比较好的方法

**那这节课和上节课的关系是什么呢？** 

在上次课，其实我们介绍了value function approximation也就是action value或者是state value，之前是用表格形式表达，现在我们可以用函数的形式来进行表达，这次课这个思想是有点类似，之前我们是用表格来表达策略，现在其实我们也可以用函数来表达策略

从上节课到这节课其实有一个跳跃是什么呢？就是之前所有的方法都是被称为value-based，这次课所介绍的方法包括下次课的方法，它们都是policy-based  

**什么意思呢？**

所谓value-based就是以value为核心，比如说我估计一个策略它的action value，这个就是police evaluation，然后在这个基础上我选择更好的策略，再去进行采样然后不断地迭代循环，这个过程当中value发挥了非常重要的作用

但是policy-based方法它是直接建立一个目标函数，这个目标函数就是策略的一个函数，我通过优化这个目标函数就可以直接得到最优的策略，在学完这次课之后大家就会明白我在讲什么，也可以预告一下，下次和我们所介绍的actor-critic的方法，也是非常非常重要的方法

它实际上是把policy gradient和这个基于value function approximation这两种方法给结合起来了，大家可以关注一下，这个就是我刚才所介绍的，这里就不再赘述

## 大纲

这是我们这次课的大纲

首先我会介绍一下policy gradient基本的思路，其实它的基本思路是非常简单的，这个也反映在了234节，也就是首先我们会定义一个metric，这个metric可以来定义什么样的策略是最优的，有了这个metric之后其实我们就去做优化，怎么做优化呢？

最简单的方法就是梯度上升的方法，这里我们是要最大化这个metric，那就梯度上升，如果最小化就梯度下降，为了应用梯度的方法

首先我要计算出来这个metric所对应的梯度是什么，之后我们就给出来这个梯度上升的方法，其中涉及到一些技巧，我们会给出一个比较特别的叫**REINFORCE**的一个算法，是**非常早期的policy gradient**的一个方法，但是是非常经典的方法 

在此基础之上，我们可以推广得到很多其它的非常最流行的方法，首先我们来介绍一下policy gradient，它基本的思路是什么

到目前为止，其实我们所有的策略全都是用表格来表示的，比如说我有一些状态每一个状态就对应这个一行，我有一些action，每一个action就对应一列，我想去里边找，某一个状态下我take action a3它的概率是多少呢？

我直接去这个表格当中就能找到，所以之前的策略，全部是用表格的形式来表达的，它表格的基本操作还是比较简单的，我想去里边访问一个量，或者是我想改变一个量直接通过索引就可以实现

下面我们会把表格改成函数，这时候π的写法也发生了改变，和之前很类似但唯一的就是后边我多了一个θ，这个θ是一个向量，可以用来表示π这个函数里边的参数

现在用的最广泛的这种函数的形式实际上就是神经网络，比如说这是一个神经网络然后它的参数是θ，它的输入是s，它的输出是对应所有的这个，比如π(a1|s,θ)一直到π(a5|s,θ) 

假如说我有5个action的话，注意之前我们在介绍value function approximation当中，value function它的参数我们用w来表示，然后policy这个函数它的参数我们用θ来表示

我们用函数来代替表格的一个好处，其实和之前介绍value function approximation是类似的，比如说state space非常大，有非常多的state，甚至这个state是连续变化的那有无穷多个，这时候这个表格形式就比较乏力了

体现在第一个是存储上面，我可能要存储非常多的数值，另外就是泛化能力上面也不如这个函数形式好

**我这里稍微说一下泛化是怎么回事**

就是比如说我要去更新π(a|s) ，那么我如果用表格的话，我必须要访问到s和a我才能去更新这个π(a|s)

但是如果用函数的话就不需要，就是我访问了(s,a)它旁边的那个(s,a)，因为那个(s,a)我更改了这个函数的参数也会导致，现在我感兴趣的这个(s,a)也会被更改掉，所以就意味着我用更少的这种访问和数据，就能得到一个比较好的效果，这就是泛化能力，我们在上节课介绍value function approximation的时候也介绍了，π的形式其实可以有多种 ，这里边我就写成这种方式

你也可以把里边比如这个竖线给去掉，或者把这个θ放到下标上去等等都可以，我们用表格和函数来进行表示它们的区别是什么呢？

刚才其实我们也提到了下面我们再正式介绍一下，基本上有3点，第一点就是我怎么样去定义一个最优的策略，如果用表格来表示一个策略

**大家还记得一个策略最优的定义是什么吗？** 

那个策略最优的定义就是，假如说这个最优的策略是$π^*$，那么$vπ^*(s)$ 也就是它所对应的state value，必须要大于等于vπ(s) 对任何其它的策略π，也就是$π*$的state value

要比其它所有策略的state value都要大，那这个是在表格情况下最优策略的定义，如果是在函数情况下就会不同，这时候其实我们会定义一个scalar metric，一个标量的目标函数

然后我们去优化这个目标函数，这个标量的目标函数是什么，接下来我们就会介绍

总而言之就是它们因为对最优策略的定义不同，也会导致它们很多细节上会不同，**第二个不同是什么呢？** 

就是我怎么样去获取一个action它的probability，如果是之前我用表格形式的话，我想获取在s  take action a它的概率是什么，直接去查表就可以了，非常的简单

现在其实也很简单只不过会稍微麻烦一点是什么呢？就是我不能直接去索引了，因为不是一个表格我得算一下，比如说它是神经网络我得把s输进去让它向前传播一次，得到它的输出π(a1|s,θ) 等等π(a5|s,θ)

我再传播一次计算一次，我才能得到它的概率是多少，第三个不同和第二个不同是比较类似的，就是我怎么去update一个策略

如果是表格的话其实之前我们说了π(a|s)我想改变它的值，我直接去表格里面去改变就可以了，非常直截了当

但是如果是用函数形式的表达就不能这么做了，因为这时候函数是用一个θ来表示的，你希望去改变π(a|s) ，你不能直接去进行赋值了

你只能去通过一定的规则去改变它的θ间接地去改变π(a|s)，这个就是三个基本的不同点，下面我们来简要地概述一下

**policy gradient的基本的思路是什么呢？**

第一个我们需要有一个目标函数来定义最优的策略是什么，那我们这里就取这个J(θ)作为它的目标函数，具体它是什么后面我会详细地介绍，这个θ就是策略所对应的参数，不同的策略不同的参数也就是有不同的J(θ)值，所以我希望这个J(θ)能够被最大化，所对应的θ比如说$θ^*$ ，那它应该是 $\max J(θ)$

有了目标函数之后我们就可以做优化，最简单的优化算法就是基于梯度的方法也就是这个，θt+1=θt+α▽J(θt)， 所以整个的思路其实是非常非常简单的，但是会有比较复杂的东西出现在什么地方呢？

就是第一个，我怎么取这个目标函数，你会发现这里面还是有一些学问的，我怎么去求解这个目标函数所对应的gradient，到时候大家就会知道一个非常著名的定理，policy gradient这里面也会有比较复杂的地方，这些所有的东西我们这节课都会进行详细的介绍



## 目标函数 1-Average value

刚刚我们介绍了policy gradient它基本的思路是什么，我相信这个思路还是比较简单的，下面我们就要基于这个基本的思路展开比较具体的介绍，这个分为三个部分：

第一个是我们介绍所选中的这个metric，也就是objective function是什么

第二个这个objective function所对应的gradient是什么

第三个我们怎么用这个gradient来做优化得到最优的策略

我们首先来看一下这个metric是什么，这部分其实内容还是不少的，我们下面一个一个来看

首先大家在读书或者是论文的时候，你经常会遇到两大类的metric第一大类是什么呢？

叫average state value或者叫average value它是什么呢？其实就是state value的一个加权平均我们来看一下，就是这样一个式子 

在右边vπ(s)是对应s的state value，d(s)是给s的一个权重，这个权重是大于等于0的，并且所有权重之和等于1，把这个给加起来，实际上就是vπ(s)的一个加权平均，得到的这样一个数我们就认为它是metric，用vπbar来表示，上边这一横线代表的就是平均的意思

显然vπbar是策略的函数，不同的策略对应的它的值也不同，所以我们就可以去优化，找到一个最优的策略让这个值达到最大，vπbar在这里实际上是state value的一个加权平均

这个其实是非常自然的一个选择metric的一个方法，d(s)就是一个权重并且所有的s它的d(s)加起来等于1，在这种情况下d(s)它不仅仅可以理解成权重，也可以理解成是probability distribution，也就是d(s)代表了状态s被选中的概率

在这种情况下，刚才的objective function就可以写成这个样子，这个就是完全依赖于expectation的这样一个定义，**我们也可以把它再写回去它等于什么呢？** 

它就等于∑sp(s)vπ(s) p(s)就是选择s的概率，这里的p(s)就是对应的我们的d(s)，所以这两个式子实际上是一样的，那么这样一个相乘然后再相加的式子，显然是可以写成一种更简洁的就是两个向量的内积

一个是d一个是vπ，这里边的d和vπ都对应两个向量，它们当中的每一个元素都对应一个状态，这里边的d(s)对应的是状态s它的权重或者是概率；这里边的vπ(s)对应的就是s的state value

那这样一个比较简洁的式子其实我们在分析，怎么样去求解vπbar的它的梯度的时候会有用

那这就是我们介绍的第一个metric，但是还没有介绍完，为什么呢？

因为里边有一个d，vπbar=∑d(s)vπ(s)，这个d(s)其实我们还没讲，那我们下面来讲一讲我们怎么去选择这个d(s)，那这时候又有两种情况

**第一种情况是d(s)和π是没什么关系的** 

它是独立的，这种情况相对来说是比较简单的，当然大家可能会猜到了

**另外一种情况就是d是依赖于π的**



**我们先来看d和π没有关系 为什么说它简单呢？**

就是因为vπbar它是等于向量的形式dTvπ，我们刚才说了，**如果这个d和π没有关系**，那我待会我再求它的梯度的时候，这个$d$就不涉及到任何的梯度所以我会只求一个$vπ$的梯度

**如果d和π有关系**，那我求梯度的时候，当然也要求这个d关于这个π的梯度，所以相对来说会麻烦一点

具体的之后大家也会看到，在这种情况下为了表明这个d和π没有关系，我们就把d写成d0，相对应的vπbar就写成vπbar0，实际上虽然说这个d可以和π没有关系，但我们还没说怎么选择这个d或者在这里边就是d0

**怎么选呢？** 

第一个最容易想到的情况就是把所有的状态，我认为它是equally important，就是每一个状态我所给它的权重或者是概率都是相同的，这里边这个就是对应的是n也就是状态的个数，所以每一个状态它的权重都是1/n，一共有n个状态，那相加最后就等于1，所以这个实际上是一个均匀分布

**另外一个其实非常重要的情况是什么呢？** 

就是我可能非常关心某一个状态s0，比如说在一些游戏最开始的时候，它总是从那个画面开始，那个画面实际上就对应一个特定的状态s0，那从那出发我希望我能够得到的reward是越大越好，在这种情况下我就不能对所有的状态都一视同仁了

那我可能要对一些状态有所偏好，那在这个极端情况下就是我只关心s0，从s0出发我所得到的reward越大越好，那这时候我就给s0它的权重d0(s0)=1，然后给所有其它不是s0它的权重就是0，在这种情况下vπbar也就变成了vπ(s0)，我去最大化这个vπbar

实际上就是最大化从s0出发我能得到多大的return，另外一种情况，刚才是d和π没有关系，现在d和π有关系，这个是一种非常常见的选择，**这时候选择什么呢？**

选择d为dπ(s)，这时候dπ(s)是叫stationary distribution，大家对dπ还有stationary distribution可能会比较熟悉，因为在上节课当中其实我们进行了比较详细的介绍，当然在书里边也有 

这里边我只简要地介绍一下，简单来说就是我有一个策略，然后我跟随那个策略去不断地和环境进行交互，当我执行那个策略很多很多次之后我就可以预测，在某一个状态就是agent在那个状态它的概率是多少，也就是那时候会逐渐达到一个平稳的状态，而且这个概率其实可以直接通过这个式子给计算出来，dπ是一个向量，它的转置乘以Pπ等于dπ的转置，这里Pπ是state transition probability matrix

也就是当我知道了Pπ之后，其实我可以直接把dπ给求解出来，当然这个Pπ我们也是不知道的，反正它是满足这样一个式子，更多我这里就不再展开了，因为一展开东西就多了去了，所以大家如果不熟悉或者感兴趣，你就回到我上节课当中或者去我书里边去看具体的细节，反正在这用一句话概括，那就是dπ是依赖于π的一个distribution，那这时候如果我根据某一个策略来执行，肯定有的状态我会访问得多一点有的状态访问得少一点，那么访问多的那个状态，实际上它的概率对应的这个dπ(s)相对来说会大一点，相对来说我给它的权重也会大一点，访问少的那些状态它的权重自然就会少一点

## 目标函数 2-Average reward

下面我们来说第二个metric，刚才是average value，现在是average reward或者叫average one-step reward

**具体是什么呢？** 

就是这样一个表达式，那我们来看一下，这边刚才是vπ(s)，现在变成了rπ(s)，rπ(s)是从s出发我所得到的单步的就是immediate reward的一个平均值，具体的表达式我待会会给出来

dπ(s)是s所对应的权重，从这个下标大家看出来了，它实际上是stationary distribution，它是依赖于这个策略π的，然后我把rπ(s)做一个加权平均，得到的这个metric就是我们的第二个metric rπbar，这个bar，就是上面这条横线也是代表一个平均的意思，然后这个dπ(s)因为它是一个概率分布，所以我们就可以把这个和式，写成这样一个expectation的形式，那么我们刚才说的这个rπ(s)具体它表达式是什么呢？

表达式就是这个，也就是在s我能得到的，immediate reward它的平均值是什么呢？

我在s其实我有很多个action我可以去选择，那我选择action a它的概率就是这个，我选择完action a之后我所得到的reward就是这个，我再把它给加起来这个就是rπ(s)，那么r(s,a)代表什么呢？

代表的是我在s我take action a之后，我所得到的immediate reward的一个平均值，这个又可以写成这样一种形式，也就是我在s我take action a，我得到的reward求一个平均就是r(s,a)，它也可以写成这样一种形式，所以总的来说就是r(s,a)，这个是我在(s,a)我得到的immediate reward

然后我对这个a求加权平均或者求expectation它是一样的，我就可以得到rπ(s)，这个是在s我所得到的immediate reward一个平均值，然后我再对s再求expectation或者加权平均，就得到了rπbar就是第二个metric，然后这里边dπ是stationary distribution

这个就是第二个reward，下面我要给第二个reward的另外一种形式

大家在论文和书籍当中，你在阅读的时候我相信你会经常遇到，我们来看一下是什么呢？

就是有一个策略，然后我根据这个策略我形成了一个trajectory，然后沿着这个trajectory我得到了很多的reward：RT+1 RT+2等等，我下面怎么做呢？

我把所有的这些reward加起来，我假设从状态s0出发，我加起来完了之后我求expectation，因为这些都是随机变量，然后我再求一个平均就除以n，然后再求一个极限当n趋向于无穷的时候

那这样一个式子它当然可以简化成，我就把里边加写成这样一个 $\sum$ 的形式，这个就代表什么呢？

就代表我从某一个状态出发然后跑无穷多步，但我这时候不是求它的所有reward它的和，而是跑无穷多步reward它的平均是什么

这个它又可以写成这种形式，什么呢？

就是刚才这里边不是我从s0出发吗？然后这边大家看s0没有了，为什么呢？

因为s0不起作用，就是你跑了无穷多步之后，你最开始从哪开始的其实已经不再重要了，我们就得到这样一个式子，这个式子是大家在论文当中你可能会经常看到的一个式子，当你看到这个式子的时候我希望你能明白，在我的课程当中我已经非常清晰地给你讲了，这个式子是什么呢？

它就是rπbar，也就是它是能够写成这种dπ(s)rπ(s) 然后求一个加权平均，然后就是我们刚才所介绍的第二个metric rπbar

为什么呢？

具体的细节我这里就不能再展开了，大家可以到我的书当中去看具体的细节，涉及到一些数学但是其实也没那么复杂

总而言之，未来当你看到这个metric的时候，不要忘了我们在这个课程当中其实讲过，刚刚我们介绍了两个metric，下面我们对这两个metric进行进一步的补充，之后会有一个小小的例子，我们要补充的第一个是什么呢？

就是这些metric全都是策略的函数，无论是vπbar还是rπbar，然后这个策略是一个函数，它的参数是θ，那所以刚才这个vπbar或者rπbar它们都是θ的函数，那么自然不同的θ就会得到不同的metric的值，那里面就存在一个最优的
