## Bellman eqution：Derivation

下面我们来介绍第三部分贝尔曼公式，首先我们要介绍的是如何来推导贝尔曼公式，刚才其实我们已经定义了state value，并且通过例子说明了state value是非常重要的，所以下面就是我们要怎么样来计算

要计算的主要的工具就是这个贝尔曼公式

贝尔曼公式用一句话来描述就是，它描述了不同状态的state value之间的关系
我们下面来推导贝尔曼公式，我首先要提醒的是，这部分可能看上去会有一些数学，但实际上并没有那么难，所以我希望大家能够稍微耐心一点

同时我们刚才通过motivating example，已经建立起来了一些直观的概念，这些直观能够帮助我们更好地去理解这些数学

首先考虑这样一个trajectory

![image-20260508204707701](https://cdn.jsdelivr.net/gh/dearRongerr/PicGo@main/202605082055425.png) 

我从St出发take action At，然后得到了这样一个trajectory，这个trajectory我可以计算它的discounted return Gt

这个其实我们刚才也已经看过了这里面新的东西是什么？

⭐️ 就是我把Gt分成两部分，我把这个γ提取出来，然后括号里边这一部分实际上就是Gt+1，所以Gt这个时刻我所得到的return等于什么呢？等于我能得到的立即得到的immediate reward，再加上我到下一个时刻，从那出发我能得到的return再加上这个discount rate，这个是我们刚刚已经介绍过的state value的定义

![image-20260508205535342](https://cdn.jsdelivr.net/gh/dearRongerr/PicGo@main/202605082055087.png) 

我们把这个Gt分成这两部分，一个是immediate reward；一个是future reward，因为这个expectation对这个加号实际上它可以分开，所以这个我们就得到了两个expectation

下面我们要做的就是分别分析这两个expectation，计算出来它们的形式这样我们就得到了贝尔曼公式

![image-20260509100421336](https://cdn.jsdelivr.net/gh/dearRongerr/PicGo@main/202605091018650.png) 

首先我们来看第一个expectation它是什么呢？当前时刻我在状态s，然后我得到的immediate reward是Rt+1

它的mean是什么？

它的mean就是通过这个式子可以体现出来我们过一遍，首先我在状态s其实我有多个action可以去take，我take action a它的概率就是π  $\pi(a|s)$ ，当我take action a我所得到的value就是这个 $\mathbb{E}[R_{t+1}|S_t=s,A_t=a]$

这个 $\mathbb{E}[R_{t+1}|S_t=s,A_t=a]$ 是什么呢？这个就是这一项  $\sum_r p(r|s,a)r$ ，我从s出发我take action a，我得到r reward的的概率是这个  $p(r|s,a)$ ，然后 $r$ 它本身的值是这个 $r$ ，所以根据expectation的定义那就是这一项，这就是第一项的表达式

第一项究竟是什么呢？

> 它实际上很简单，它就是我能得到的immediate reward的一个mean，一个expectation

![image-20260509100831771](https://cdn.jsdelivr.net/gh/dearRongerr/PicGo@main/202605091018651.png) 



我们再来看第二项，第二项是我从当前状态是s，我从s出发我所得到的下一个时刻的return的mean

这个是有点意思的我们来看一下它等于什么呢？它等于我从当前s出发其实我有多个选择，我可以跳到不同的s'我跳到不同s'的概率是这个 $p(s'|s)$ 

我跳到不同s'我所得到的值是这个  $\mathbb{E}[G_{t+1}|S_t=s,S_{t+1}=s']$  ，一相加 $\sum_{s'}$ 就是这个expectation

我们来看一下第一个这个值 $\sum_{s'} \mathbb{E}[G_{t+1}|S_t=s,S_{t+1}=s'] p(s'|s)$ 是什么呢？是我当前的状态是s我下一个状态是s'，然后我计算从下一个状态出发我所得到return的mean

这个当中有一项是这个 $S_t=s$ 其实可以是去掉的为什么呢？因为我已经知道了下一个状态是s'，其实我就不用关心我之前究竟是在什么状态了，所以这个conditional expectation，就等于这个conditional expectation，这个性质实际上就是markov的性质，也就是memoryless的一个性质我没有记忆的

我们从这再出发这个  $\mathbb{E}[G_{t+1}|S_{t+1}=s']$ 是什么呀？我从下一个状态s'出发，我计算下一个之后我所能得到的return的平均值，这就是一个state value只不过它是针对s'的state value，所以我们就得到了这一步 $v_{\pi}(s')$ ，然后再往下这个其实我们还没有计算

从s到s'它的概率是什么呢？从s出发其实我有多种选择我可以选择不同的action，我选择这个action的概率是这个 $\pi(a|s)$ ，那么我选择这个action我所得到的，我跳到s prime（s'）的概率是这个 $p(s'|s,a)$ ，所以这个通过相加我就可以得到，所以这个就等于从s到s'的概率

所以这里边其实我们用到了概率论当中的很多小的技巧，大家如果对概率论还不太熟悉的话，可以去看一下我们那本书当中附录当中的一些介绍



总而言之第二项是什么呢？是future reward的一个mean

在计算第二步的时候实际上我们可以把这个去掉，那这个就是因为memoryless markov property

首先上面一大串就是传说当中的贝尔曼公式，它在干什么呢？它实际上就描述了不同状态的state value之间的关系，为什么这么说呢？

大家可以看一下，左边是s的state value $v_{\pi}(s)$ ，右边是s prime（s'）的state value  $v_{\pi}(s')$

所以它们的关系就可以通过这样一个式子表达出来，另外这个式子包含两项
第一项实际上是immediate reward一个term一个mean $\sum_a \pi(a|s) \sum_r p(r|s,a)$ 

第二项是future reward一个term $\sum_a \pi(a|s)\sum_{s'}p(s'|s,a)v_{\pi}(s')$ 

此外非常非常重要的一点就是这不是一个式子，这个式子是应该对于状态空间当中所有的状态都成立的，==所以如果我们有n个状态那么我们就会有n个这样的式子==

通过这n个式子其实我们就可以把state value给求解出来，但是我们通常写的都是写这样一个式子

📢 所以大家千万不要以为，贝尔曼公式就是只有这一个式子

![image-20260509104752738](https://cdn.jsdelivr.net/gh/dearRongerr/PicGo@main/202605091302714.png)  

另外就是下面它的state value $v_{\pi}(s)$ 是我们要计算的

但是怎么计算呢？其实就是bootstrapping

直观上来说我这边有一个state value $v_{\pi}(s)$ 我要计算，但是我依赖于其它状态的state value  $v_{\pi}(s')$ 好像没法计算，就像我刚才说的我们实际是有一组这样的式子

我把这些式子联立就可以计算出来，这个式子其实依赖于很多概率

像这个概率 $\pi(a|s)$ 、  这个概率 $p(r|s,a)$ 、和这个概率 $p(s'|s,a)$ 

首先对于概率 $\pi(a|s)$ 是什么呢？它就是policy，所以贝尔曼公式它是依赖于policy的

如果我们能够把这个state value给计算出来，实际上我们在做的一件事情就叫policy evaluation，就是去evaluate这个policy究竟好还是坏

另外两个概率 $p(r|s,a)$ 和 $p(s'|s,a)$  就这个它们是什么呢？
它

们实际上就是 dynamic model或者叫environment model

这里又分两种情况

- 第一种是我们知道这个model，在本节还有下节当中，其实我们都会假设我们知道这个model，我们会给出来相应的算法
- 如果我们不知道model我们仍然可以求出来state value，但那个就是model free reinforcement learning的算法，那个我们未来会重点介绍

## Bellman equation：Matrix-vector form

在上一部分我们介绍了贝尔曼公式的推导，下面我们来介绍贝尔曼公式的矩阵和向量的形式，当我们有了一个贝尔曼公式之后，我们其实要考虑的就是怎么样求解这个贝尔曼公式，大家可以看到这是我们刚才得到的贝尔曼公式的表达式，左边是有一个state value右边是有另外一个stated value，也就是从单单这一个公式当中，其实我们要求出来这个state value是不可能的，但是我们注意到这个elementwise form，也就是针对每一个state value的这样一个equation，对所有的状态都是成立的，如果我有n个状态那么我就会有n个这样的equation，如果我把所有的这些公式放在一起那我就得到了一组，那我进一步就可以整理成一个matrix-vector form，这个形式对我们求解和理解问题其实非常有帮助

**<u>*关于迭代解*</u>** 

大家比较一下这个式子，和刚才的贝尔曼公式的这个式子其实非常像，中间这几项是一样的 ，只不过这边vπ变换成了vk，这边的这个vπ也换成了vk+1，这个算法我怎么样使用呢？

原始贝尔曼方程 $v_{\pi} = r_{\pi} + r P_{\pi}v_{\pi}$ 

迭代解贝尔曼方程用法 $v_{k+1}=r_{\pi}+\gamma P_{\pi} v_k$ 

首先，我这边是vk这边是vk+1

从最开始从第0个，我可以随便猜一个vπ是等于什么，比如说全都是 0 ，然后我通过这个式子我代入，把vk代到右边左边我就可以计算出来v1，因为这些都是事先知道的， 然后我把v1再代到右边

我就可以得到左边的v2， 我再把v2代到右边

我就可以得到左边的v3 这样一直下去

我就会得到这样一个序列v0 v1 v2 一直到vk

实际上我们可以证明当k趋向于无穷的时候，vk就收敛到了vπ 这个vπ就是真实的state value
