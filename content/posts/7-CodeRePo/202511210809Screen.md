> 场景：断开学院服务器连接，代码能继续跑吗，得看学院服务器有没有后台托管代码。推荐开 screen，防止后台断开连接，养成好习惯。



```bash
screen -ls
screen -S Screen_name
screen -r XXXXX
```
### 会话 & 窗口

- Screen 里可以同时跑无数个" 窗口 "，一个 screen是相同的进程，不同的窗口是子进程
- 一个窗口跑实验，一个窗口开 TensorBoard

窗口常用快捷键：

```bash
# 不退出当前会话，开新窗口，C = Create
Ctrl + A + C       

Ctrl+A  N          # 下一个窗口
Ctrl+A  P          # 上一个窗口
Ctrl+A  "          # 列出所有窗口，数字键直接跳
```

- 脱离 Screen（让两个窗口都在后台跑）

```bash
Ctrl+A  D          # Detach，两个任务都活着
```
