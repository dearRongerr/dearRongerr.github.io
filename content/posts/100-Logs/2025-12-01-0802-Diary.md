## 2025-12-03 Wednesday 

- 我笑死，怎么下载个 b 站音频，还得用 docker😂😂😂
- 记得先把桌面的 docker 打开，能少一次报错 

```bash
>> pwd                                 
/Users/dearr/bilibili-downloader
```

- 本地下载

```bash
git clone https://github.com/foamzou/bilibili-downloader.git
cd bilibili-downloader
docker-compose up -d
```

- 复制音频命令
- wps 技术路线模版
- `docker-compose up -d` 总是报超时的错误：
  - ① 区分浏览器设置的代理不代表 docker 在 bash 中也能用，所以一直报超时的错误，因为 bash 中没有代理 
  - ②解决的方法是 手动下载下载 image，然后本地构建 
  - ③ docker desktop 设置代理的方法是，settings>>Resources>>Proxies 中的 http、https 都改 `http://127.0.0.1:7890` 然后点击 Apply & restart 即可 
  - ④ 将 docker 的镜像都设置为空，这样就不会总是找镜像的地址 settings>>Docker Engine>>改 `"registry-mirrors": []` 即可>>Apply & restart
